# AI-Assisted Developer Productivity Prediction

## Introduction

**AI-Assisted Developer Productivity Prediction** is a machine learning and data mining project that explores how software developers use Artificial Intelligence (AI) tools and how AI-assisted development is related to perceived productivity improvement.

The project uses data from the **Stack Overflow Developer Survey 2025** to analyze AI-assisted tasks, AI agent usage, AI attitudes, AI frustrations, and developer characteristics. Machine learning techniques are applied to classify developers into different levels of perceived productivity improvement, while association rule mining is used to discover common patterns in AI usage.

A web-based application is also developed to present the analysis, visualization, association rules, and productivity predictions in an interactive and user-friendly interface.

## Project Objectives

* Analyze AI-assisted development practices among software developers.
* Identify common combinations of AI-assisted tasks and usage patterns.
* Examine relationships between AI usage, attitudes, frustrations, and productivity.
* Develop a machine learning model to predict perceived productivity improvement levels.
* Present the results through an interactive web application.

## Dataset

The project uses the **Stack Overflow Developer Survey 2025** dataset. The analysis focuses on professional software developers and includes information related to AI usage, development activities, AI agents, AI experiences, and developer characteristics.

## Purpose

This project aims to provide data-driven insights into AI-assisted software development and explore how different AI usage patterns and developer experiences are associated with perceived productivity improvement.
